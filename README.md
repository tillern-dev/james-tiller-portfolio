# James Tiller Munyerere — Personal Portfolio

Personal developer portfolio branded with **TILLERN LABS** in dark, gold and white.

**Building Ideas Into Digital Reality.**

A responsive static website with About, Projects, Skills and Contact sections, mobile navigation, favicon, SEO metadata and animations.

## Deploy

Import `tillern-dev/james-tiller-portfolio` into Vercel. Select **Other** as the framework preset and leave the build command empty. No environment variables required.
